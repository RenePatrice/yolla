# Portfolio de Faya Yolla LENO

Site statique : aucune installation, aucune commande de build.

## Déployer sur Vercel (via GitHub)
1. Mettre le **contenu** de ce dossier à la racine du dépôt : `index.html`, `docs/`, `img/` doivent être visibles directement sur la page d'accueil du dépôt GitHub.
2. Dans Vercel → Settings → Build and Deployment : Framework Preset `Other`, Build Command vide, Output Directory vide.

## Structure
- `index.html` : le site complet (textes FR/EN, styles, scripts).
- `docs/full/` : attestations et certificats en grand format (affichés dans la visionneuse).
- `docs/thumb/` : vignettes des mêmes documents.
- `docs/pdf/` : article IDEAL complet.
- `img/` : photos de la galerie.
